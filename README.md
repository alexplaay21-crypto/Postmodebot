# PostModeBot

Telegram-бот для создания и оформления постов прямо в чате: текст (с HTML‑разметкой),
фото/GIF/файл, кнопки-ссылки — и публикация в выбранный канал или группу.

В отличие от исходного проекта (PostOrbit — консольный скрипт, который просто
отправлял заранее заготовленный `message.txt`/`message.json` через терминал),
PostModeBot — это полноценный интерактивный **Telegram-бот**: всё оформление
поста происходит через диалог с ботом прямо в мессенджере, без правки файлов
и без терминала.

## Возможности

- 📝 **Пошаговое создание поста**: текст → медиа (фото/GIF/файл, опционально) →
  кнопки-ссылки (опционально) → куда отправить → предпросмотр → подтверждение
- 🖋 Поддержка HTML-разметки в тексте поста (`<b>`, `<i>`, ссылки и т.д.)
- 🔘 Инлайн-кнопки со ссылками, любое количество, каждая на отдельной строке,
  с необязательным **цветным кружком** (🔵/🟢/🔴) перед текстом кнопки
- 🎯 Отправка по `@username`, ссылке `t.me/...` или числовому ID чата
- 💰 **«Поддержать автора»** — донат через встроенные **Telegram Stars ⭐**
  (без сторонних сервисов, банковских карт и ссылок): 50 / 100 / 250 / 500 /
  1000 / 2500 ⭐ на выбор
- 🌍 **12 языков интерфейса**, автоматически подхватывается язык
  Telegram-клиента пользователя при первом `/start`, язык также можно
  переключить вручную в любой момент:
  🇷🇺 Русский · 🇬🇧 English · 🇪🇸 Español · 🇧🇷 Português · 🇫🇷 Français ·
  🇮🇷 فارسی · 🇸🇦 العربية · 🇮🇳 हिन्दी · 🇨🇳 中文 · 🇹🇯 Тоҷикӣ ·
  🇮🇩 Bahasa Indonesia · 🇯🇵 日本語
- ⚠️ Понятные локализованные подсказки при типичных ошибках Telegram
  (бот не в чате, не хватает прав администратора, файл слишком большой и т.д.)
- 💾 Без базы данных — язык пользователя хранится в `data/users.json`

> **О «цвете» кнопок.** Bot API Telegram физически не поддерживает цветные
> инлайн-кнопки — все кнопки в интерфейсе Telegram выглядят одинаково. То, что
> делает бот — добавляет цветной эмодзи-кружок (🔵/🟢/🔴) прямо в текст
> кнопки, чтобы визуально выделить её. Это ближайшая честная имитация того,
> что просил исходный `style` в `message.json`.

> **О донате.** Telegram Stars (⭐, валюта `XTR`) — официальный встроенный
> механизм платежей Telegram. Боту не нужен `provider_token`, платёжный
> шлюз или банковский счёт — только сам Bot API.

## Установка

```bash
git clone <ваш-репозиторий>
cd PostModeBot
pip install -r requirements.txt
```

Требуется Python 3.10+.

## Настройка

Откройте `config.py` и заполните:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN"          # токен от @BotFather
ADMIN_ID = 123456789                  # ваш числовой Telegram ID (от @userinfobot)
DONATE_STAR_AMOUNTS = [50, 100, 250, 500, 1000, 2500]  # варианты доната в ⭐
```

Ничего дополнительно настраивать для приёма Stars не нужно — это встроенный
метод оплаты Telegram, он доступен у любого бота из коробки.

## Запуск

```bash
python main.py
```

Бот запускается в режиме long polling.

## Как пользоваться

1. Напишите боту `/start`
2. Нажмите «📝 Создать пост»
3. Отправьте текст поста (можно с HTML-разметкой)
4. Пришлите фото/GIF/файл или нажмите «Пропустить»
5. Пришлите кнопки, по одной в строке:
   `Текст кнопки - https://ссылка`
   Хотите цветной кружок перед текстом — добавьте третьим полем `blue`,
   `green` или `red`: `Купить - https://example.com - green` → 🟢 Купить.
   Или нажмите «Пропустить»
6. Укажите канал/группу: `@username`, `t.me/username` или числовой ID
7. Проверьте предпросмотр и нажмите «✅ Отправить»

Бот должен быть добавлен в целевой канал/группу как **администратор**
с правом «Публикация сообщений» (Post messages).

Сменить язык интерфейса в любой момент: `/language` или кнопка «🌍 Язык»
в главном меню.

## Структура проекта

```
PostModeBot/
├── main.py                 # точка входа, запуск polling
├── config.py                # токен бота, ADMIN_ID, ссылка на донат
├── requirements.txt
├── bot/
│   ├── texts.py             # загрузка локализаций, определение языка клиента
│   ├── storage.py           # хранение языка пользователя (JSON-файл)
│   ├── keyboards.py         # инлайн-клавиатуры
│   └── handlers/
│       ├── start.py         # /start, главное меню, помощь
│       ├── language.py      # выбор языка интерфейса
│       ├── donate.py        # /donate
│       └── post.py          # FSM создания и отправки поста
├── locales/                 # ru.json, en.json, es.json, ... (12 языков)
├── scripts/
│   └── generate_locales.py  # генерирует locales/*.json из одной таблицы переводов
└── data/
    └── users.json           # создаётся автоматически при первом запуске
```

## Добавить ещё один язык

1. Откройте `scripts/generate_locales.py`, скопируйте один языковой блок
   в словаре `TRANSLATIONS`, переведите значения (ключи менять нельзя)
2. Добавьте код языка и его подпись (флаг + название) в
   `SUPPORTED_LANGUAGES` и `_LANGUAGE_ALIASES` в `bot/texts.py`
3. Запустите `python scripts/generate_locales.py` — файл `locales/<код>.json`
   будет создан/обновлён автоматически
