PostModeBot

Telegram-бот для создания, оформления и публикации постов прямо в чате.

Поддерживаются текст, HTML-разметка, фото/GIF/файлы, инлайн-кнопки со ссылками, выбор канала или группы, предпросмотр, сохранение готовых постов и их последующее редактирование.

О «цвете» кнопок

Telegram Bot API не поддерживает настоящие цветные инлайн-кнопки.

Поэтому бот использует цветные эмодзи-кружки непосредственно в тексте кнопки:

- 🔵 blue
- 🟢 green
- 🔴 red

Это визуальная имитация цвета кнопки.

О Telegram Stars

Telegram Stars ("XTR") — встроенная валюта Telegram.

Для приёма Stars боту не требуется сторонний платёжный шлюз или банковский сервис.

Хранение данных

База данных не используется.

Данные хранятся в JSON-файлах:

- "data/users.json" — язык пользователей
- "data/posts.json" — сохранённые посты

Файлы создаются автоматически при необходимости.

Установка

git clone <ваш-репозиторий>
cd PostModeBot
pip install -r requirements.txt

Требуется Python 3.10+.

Настройка

Откройте "config.py":

BOT_TOKEN = ""

ADMIN_ID = 122

DONATE_STAR_AMOUNTS = [50, 100, 250, 500, 1000, 2500]

BOT_TOKEN

Получается через "@BotFather".

ADMIN_ID

Числовой Telegram ID администратора.

Важно: полноценной админ-панели в текущей версии нет. "ADMIN_ID" пока зарезервирован под будущие административные функции.

DONATE_STAR_AMOUNTS

Список доступных вариантов доната в Telegram Stars.

Запуск

python main.py

Бот работает через long polling.

Как пользоваться

1. Отправьте боту "/start".
2. Нажмите «📝 Создать пост».
3. Введите текст поста.
4. При необходимости добавьте фото/GIF/файл.
5. Добавьте кнопки или пропустите этот шаг.
6. Укажите канал или группу.
7. Проверьте предпросмотр.
8. Нажмите «✅ Отправить».

Для публикации бот должен быть добавлен в целевой канал/группу и иметь необходимые права.

Сохранённые посты

После создания пост можно сохранить.

Сохранённые посты доступны через раздел «💾 Сохранённые посты».

Для сохранённого поста доступны:

- просмотр;
- удаление;
- поиск через inline-режим;
- повторное использование;
- редактирование доступных параметров.

Каждому сохранённому посту присваивается уникальный код.

Изменение языка

Язык можно изменить через:

/language

или через кнопку выбора языка в главном меню.

Добавление нового языка

1. Откройте "scripts/generate_locales.py".
2. Добавьте новый язык в таблицу переводов.
3. Переведите значения, не изменяя названия ключей.
4. Добавьте язык в список поддерживаемых языков в "bot/texts.py".
5. Запустите:

python scripts/generate_locales.py

После этого будет создан или обновлён соответствующий JSON-файл в "locales/".

Проверка локализаций

Для проверки всех локалей используется:

python fix_locales.py

Все поддерживаемые языки должны содержать одинаковый набор ключей.
